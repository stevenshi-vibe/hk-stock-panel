# 南下拆解怎么读

这个文件只说明方法和一小组**合成**数字，用来看口径。真实的美团测算不放在公开仓库里。

合成例子：某只虚构股票在报告期当天南下持股 1,000,000 股。一只名为「合成港股通样本」的基金持有 100,000 股，一只「合成沪港深」基金持有 400,000 股，一只 QDII 持有 50,000 股，一份权益披露写着外资机构 300,000 股。

覆盖率只用第一只：100,000 / 1,000,000 = 10%。沪港深标成「可能经港股通」，QDII 和权益披露标成「非港股通」，都不加进分子。未识别是 900,000 股。

报告期如果不是南下交易日，分母用不晚于报告期的最近一个南下交易日。一季报、三季报只有前十大时，某只基金从上期消失不记成卖光。同一申报人、同一天、同一股数如果既出现在日报里又出现在合并名单里，合成一行，两个来源都保留。

真实数据的采集结果在本机索引 `data/_southbound_index.db`（已 gitignore）。有索引时个股页读索引；没有索引时退回 `focus_funds.csv` 里的关注名单。快速扫描按名称或类型筛「港股通、恒生、港股、QDII、沪港深、中概」，全量扫描不筛。扫描可以中断后再跑，已成功的基金年份会跳过。

合规和字段说明见 [southbound.md](southbound.md)。
